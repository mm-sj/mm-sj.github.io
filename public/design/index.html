DocQ

PDF 문서를 AI가 퀴즈로 바꾸고, 최대 4명이 3D 보드게임으로 푸는 실시간 멀티플레이 서비스

'다 읽었다'와 '다 안다'는 다릅니다. 읽은 문서를 이해했는지 혼자 확인하는 지루한 과정을 친구와 겨루는 게임으로 바꾸는 것이 목표였습니다. 저는 이 게임이 어떤 모습이고 어떻게 느껴질지를 정하는 역할을 맡았습니다.

정한 것

  • 동화책 톤. 혼자 하는 공부가 아니라 친구와 하는 보드게임으로 느껴져야 했습니다. 나무 패널, 파스텔 하늘, 둥근 버튼으로 보드게임 상자를 여는 느낌을 잡고 로비·대기실·커뮤니티 전체에 적용했습니다.
  • 나무색 한 가지로 글자와 테두리를. 검정 대신 짙은 나무색 #5D4037을 글자와 테두리에 함께 써서 화면 전체가 한 재질로 보이게 했습니다.
  • 누르면 들어가는 버튼. 주 버튼은 아래쪽 5px 그림자로 두께를 만들고, 누르면 그 두께만큼 내려앉습니다. 아래 견본에서 눌러볼 수 있습니다.
  • 초록 하나를 주 색으로. 나무색 바탕 위에서 초록은 GAME START 같은 주 버튼과 선택된 항목에 써서, 다음에 누를 곳이 먼저 보이게 했습니다.

대기실 화면 구성

오른쪽 열은 위에서 아래로 캐릭터 선택 → PDF 올리기 → GAME START 순서입니다. 시작하려면 해야 하는 일의 순서와 화면의 순서를 맞췄습니다.

Jabis

음성 명령을 듣고, 책상을 보고, 두 팔로 물건을 집는 AI 데스크 로봇의 운영 대시보드

AI가 스스로 판단해 움직이는 로봇입니다. 그래서 화면이 답해야 할 질문은 세 가지였습니다. 지금 연결돼 있는가, 지금 무엇을 하고 있는가, 멈추려면 어디를 누르는가. 팀의 유일한 FE로 화면 구성부터 구현까지 맡았습니다.

정보 우선순위

  • 맨 위 줄은 안전. 연결 상태, 현재 모드, E-STOP을 상단 바 오른쪽에 고정했습니다. 어느 화면에 있든 같은 자리에서 멈출 수 있습니다.
  • 가장 큰 면적은 로봇의 시야. 로봇이 무엇을 보고 어디로 팔을 뻗는지가 가장 먼저 읽혀야 해서, 디지털 트윈에 화면의 3분의 2를 줬습니다.
  • 오른쪽 열은 위에서 아래로 구체적인 순서. 인식된 물체 → 진행 중인 세션 → 시스템 로그. 요약에서 원본 기록으로 내려갑니다.
  • 색은 상태에만. 바탕과 글자는 회색 단계만 쓰고, 초록·노랑·빨강은 상태 표시에만 썼습니다. 색이 보이면 곧 확인할 것이 있다는 뜻입니다.

실제 화면의 색과 크기로 다시 그린 견본입니다. 상태마다 색과 글자를 함께 써서 색만으로 구분하지 않게 했습니다.

바꾼 결정 하나

처음에는 로봇이 움직이기 전에 작업마다 승인을 받는 구조였습니다. 개발 중에 이를 일일이 허락받지 않고 "지금 이 작업을 하고 있다"만 알리고, 원치 않을 때만 취소하는 방식으로 바꿨습니다. 알림 카드는 오른쪽 아래에 떠서 로봇 화면을 가리지 않습니다.

개발 협업 문서

  • 개발 시작 전에 좌표계, 단위, 이름 규칙을 정한 AI 코딩 가이드 문서를 써서 팀 전체가 같은 규칙으로 AI 도구를 쓰게 했습니다.
  • FE와 BE가 주고받는 데이터 형식을 맞추는 API 명세와 FE 폴더 구조, 타입 정의를 세팅했습니다.
  • 버튼은 shadcn/ui를 바탕으로 종류 6가지, 크기 8가지를 variant로 관리했습니다.

Would You Draw

감정을 그림으로 그리면 AI가 해석하고, 그 기록이 별, 별자리(7일), 은하(30일)로 쌓이는 감정 드로잉 서비스

감정을 점수로 매기는 대신 시간이 지날수록 넓어지는 우주로 보여주고 싶었습니다. 우주 화면 자체는 팀원이 만들었고, 저는 그 위의 인터랙션과 드로잉 화면, 분석 결과 화면을 맡았습니다.

AI 응답을 기다리는 화면

  • 문제. 그림을 저장하면 AI 분석이 뒤에서 따로 돌아갑니다. 분석이 끝날 때까지 우주에 아무 변화가 없어서, 저장이 실패한 것처럼 보였습니다.
  • 결정. 저장되는 즉시 임시 별을 먼저 띄우고 탄생 연출을 보여줍니다. 분석 결과가 오면 임시 별을 실제 별로 바꿉니다.
  • 확인 간격. 2 → 5 → 10 → 15 → 20초로 간격을 늘려 가며 결과를 확인하고, 확인 중에는 요청이 겹치지 않게 했습니다.

피드백으로 바꾼 것

  • 유저 피드백 37건에서 반복된 말은 "어떻게 쓰는지 모르겠다"였습니다. 첫 진입 튜토리얼과 전역 알림 모달을 넣었습니다.
  • 사용자가 고른 감정 색 중 일부는 별이 빛나지 않았습니다. 색마다 밝기가 달라 생긴 문제여서, 모든 색이 고르게 빛나도록 기준값을 낮췄습니다.
